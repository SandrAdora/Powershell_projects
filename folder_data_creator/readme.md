# Folder and File creator

This project is created in powershell. It is used to help automatise the creation of folder or Files in a prefered Directory or existing folder. 
# Functionalities 

1. User can create a non existing *`folder`* or *file* 
2. User can choose the location directory in which the folder or file will be stored 
3. Additional Functionality: 
   1. Renaming folders 
   2. Renaming files
