# Powershell_projects

This repository lists some useful automatisation projects for windows

### 1. Arbeitszeiterfassung

This script monitors the working time. 

### 2. Bildschirmmodus bearbeiten

This script edits the screen modes. If you are working on your laptop/or computer without wanting the screen to go off or going to standby mode. This skript blocks the standby mode, which can be reversed.

### 3. Delete Dublicates

This script deletes dublicates in folders.

### 4. Folder Data Creator

This script creates folders or files in the destination a user defined

### 5. Rechner Herunterfahren

This script shuts down your pc/computer by force 

### 6. Sort Download Folder

This script arranges your Download folder in folders the user set as destination 
Works for *.pdf*, *.docx*, *.xlxs* and other extensions
